# 潜在家长访谈研究领域指南

## 业务问题

招生洞察常来自销售转述或少数投诉，缺少对潜在家长决策过程、替代方案和阻力的系统访谈研究。

## 产品解决方案

设计访谈指南、执行多轮结构化归纳，区分家长原话、研究者推断和待验证假设，形成购买阻力与信息需求。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `research_questions` | 研究问题 | 是 | 购买的阻力、替代方案和决策因素 |
| `target_parent_segments` | 目标家长分群 | 是 | 地区、年龄、需求和决策阶段 |
| `region` | 研究地区 | 是 | 城市或区域 |
| `sample_criteria` | 样本标准 | 是 | 计划样本数与筛选要求 |
| `interview_notes` | 访谈记录或摘要 | 是 | 知情同意和脱敏后的材料 |
| `competitor_context` | 竞品与替代方案 | 否 | 公开发布或用户提供信息 |
| `institution_courses` | 机构课程信息 | 是 | 用于理解决策语境 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

样本小不能代表总体；需知情同意与脱敏；研究者偏差需反例和复核；不能伪造访谈或评论。
